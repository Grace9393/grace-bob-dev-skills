# Frameworks

Use one of the following framework modes.

## adaptive

Pick one framework below that best fits the question type, then continue with that framework.

## components

Focus on core elements, information needs, scope, dependencies, and perspectives.

## 5w1h

Cover who, what, when, where, why, and how.

## mece

Create mutually exclusive, collectively exhaustive branches.

## pestle

Decompose by political, economic, social, technological, legal, and environmental factors.

## systems

Analyze inputs, processes, outputs, feedback loops, environment, and stakeholders.

## scientific

Structure via observation, hypothesis, method, data, analysis, validation.

## design

Use design-thinking lenses: users, pain points, desirability, feasibility, viability, iteration.

## root-cause

Use progressive causality (5 Whys style) from symptoms to root causes.

## issue-tree

Build a hierarchical issue tree with non-overlapping branches.

## academic

Use an academic structure: definitions, literature, assumptions, methodology, evidence, limitations.
