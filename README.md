# IBM Dev, Operations & Productivity Skills — Bob BYOS Pack

126 skills covering: core coding (TDD, debugging, CI/CD, security, git), ICA/Orchestrate tooling, operations, Composio integrations, content writing, data/analytics (Daloopa), productivity, and miscellaneous utilities.

## How to connect in IBM Process Studio (BYOS)

1. Go to **Settings ? Skills ? Bring Your Own Skill (BYOS)**
2. Repository URL: `https://github.com/Grace9393/grace-bob-dev-skills`
3. Branch: `main`
4. Folder: `/` (root)
5. Enter your GitHub PAT and click **Connect**

> **Note:** Each subfolder is one skill. The folder name must match the `name:` field in its `SKILL.md`.
