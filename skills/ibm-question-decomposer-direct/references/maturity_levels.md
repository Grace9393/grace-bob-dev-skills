# Maturity Levels

Use these labels for each leaf-node maturity assessment.

1. Initial
2. Developing
3. Defined
4. Managed
5. Optimizing

Specificity requirements (mandatory):

- Every level answer must be specific to the exact leaf question.
- Include concrete evidence terms that match the question, such as named artifacts, controls, owners, thresholds, SLAs, or monitoring signals.
- Do not copy the same 1-5 phrasing across different leaf questions.
- Ensure monotonic progression in capability from Level 1 to Level 5 for the same leaf.
- If a criterion sounds interchangeable across unrelated questions, rewrite it.

Template:

- Leaf: `<node_id> <leaf question>`
- 1 Initial: `<question-specific criterion showing ad hoc or missing practice>`
- 2 Developing: `<question-specific criterion showing partial or pilot practice>`
- 3 Defined: `<question-specific criterion showing standardized and documented practice>`
- 4 Managed: `<question-specific criterion showing measured and enforced practice>`
- 5 Optimizing: `<question-specific criterion showing continuous optimization or predictive improvement>`
